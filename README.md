# CARSHARE — полноценный интерактивный frontend

Демонстрационный веб-сервис каршеринга на **Astro 5 + React 19 + TypeScript**.
Вдохновлён переданными экранами Figma; интерфейс переработан в самостоятельный адаптивный продукт.

## Запуск

Требования: Node.js 20.11+ (рекомендуется Node.js 22), npm.

```bash
npm install
npm run dev
```

Откройте http://localhost:4321

Продакшен-сборка:

```bash
npm run build
npm run preview
```

Артефакт для статического хостинга будет в папке `dist/`. Подходит для Vercel, Netlify, Cloudflare Pages, GitHub Pages (при настройке base для вложенного URL). SSR-сервер для текущего демо не требуется.

## Реализованные пользовательские сценарии

1. Главная, описание сервиса, тарифы и карта автомобилей.
2. Карта Алматы: выбор машины через маркер и список, поиск, фильтры по категориям, карточка и тариф.
3. Регистрация: телефон → тестовый код → имя и номер водительского удостоверения → локальный аккаунт.
4. Бронирование выбранной машины, 10-минутный таймер ожидания, отмена.
5. Предпоездочный осмотр, фото и описание обнаруженного повреждения.
6. Открытие авто (демо-имитация) и старт аренды.
7. Таймер поездки и отображение расчётной стоимости, переключение парковочного режима.
8. Завершение: чек-лист → загрузка минимум двух фотографий → закрытие поездки.
9. Экран результата, история поездок, детали и расчёт суммы.
10. Платежи и тестовая карта, журнал операций.
11. Центр поддержки: FAQ, демо-чат, экстренная помощь / номер 112.
12. Уведомления, прочтение уведомлений, профиль, выход, сброс локальных данных.
13. Mobile UI: адаптивные экраны, нижняя навигация, фильтры, интерактивные модальные окна.

## Архитектура

- `src/pages/index.astro` — предельно компактный HTML shell и точка входа.
- `src/components/App.tsx` — типизированный React UI и модель сценариев.
- `src/components/style.css` — стили, responsive layout, состояния UI.
- `astro.config.mjs` — статическая сборка Astro + React integration.
- `localStorage` с ключом `carshare:v1` — демонстрационное хранилище состояния между перезагрузками.
- Иконки — `lucide-react`.
- Шрифт Manrope загружается через Google Fonts, системный sans-serif используется как fallback.
- Карта — стилизованная **демонстрационная схема**, не GPS-карта и не картографический API.
- Изображения автомобилей — удалённые демонстрационные изображения с Unsplash; при недоступности сеть не блокирует интерфейс.

## Важные ограничения: frontend, не реальная каршеринговая платформа

Это **полноценный кликабельный frontend-прототип с рабочим end-to-end DEMO-флоу**, но без backend и реальных аппаратных интеграций.

- Нет настоящей регистрации, SMS/OTP, KYC, проверки водительского удостоверения и водительского стажа.
- Нет GPS, геозон, адресной геокарты, маршрутизации, реальных координат и остатков автопарка.
- Нет блокировок инвентаря, конкурентного бронирования или серверного таймера.
- Нет телематики, разблокировки автомобильных замков и удалённых команд.
- Нет эквайринга, фискализации, настоящих транзакций, перерасчёта по тарифной сетке.
- Нет файлового хранилища, фото сохраняются только в памяти вкладки и не выгружаются на сервер.
- Чат работает с локальным автоответчиком; оператора нет.
- Демо-коды подходят любые четырёхзначные; **не вводите здесь реальные секретные сведения или данные банковской карты**.
- Данные аккаунта и история хранятся в localStorage, без шифрования; предназначены только для демо.
- При перезагрузке активная аренда демонстрационно восстанавливается, но таймер не является серверно-авторитетным.

## Что требуется для реального запуска на рынок

Рекомендуемые сервисы: backend API (авторизация и сессии), Postgres/PostGIS (машины/аренды/геозоны), Redis (TTL брони, состояния), SMS-провайдер, KYC/проверка водительских удостоверений, PSP (токенизация карт, 3-D Secure, webhooks, возвраты), телематический шлюз с защищёнными командами и аудитом, геокарты (Mapbox/2GIS/OSM), S3-совместимое хранилище фото, служба поддержки, billing и тарифный движок. Для аренды важны права, страхование, оферта, регламент ДТП, защита персональных данных и юридическая проверка требований Казахстана.

## Пример проверки демо

1. «На карте» → выберите Hyundai Elantra → «Забронировать».
2. Создайте тестовый аккаунт (телефон, любой код `1234`, любое вымышленное ФИО и тестовый номер удостоверения).
3. Снова нажмите «Забронировать» → «Я у автомобиля» → «Всё в порядке» → «Открыть и начать поездку».
4. Перейдите к завершению, отметьте 5 пунктов чек-листа и загрузите 2 фотографии.
5. Проверьте сумму поездки, историю поездок и платежи.

## Производительность

Astro отдаёт статический HTML без серверного runtime. React гидратируется только в единственном приложении (`client:load`); для следующей итерации рекомендуется изолировать интерактивные области отдельными Astro islands, подключить виртуализацию списков и реальную карту лениво по запросу. Фактические показатели Lighthouse/Web Vitals следует измерить после установки зависимостей и развёртывания.
