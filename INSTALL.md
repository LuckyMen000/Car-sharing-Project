# CARSHARE — установка полного проекта

Это полный исходный проект с объединёнными обновлениями. **Не накладывайте его поверх старой папки**: распакуйте в новую папку.

Требуется Node.js 20+.

```bash
cd shipa-drive
npm install
npm run dev
```

Откройте http://localhost:4321

Проверка сборки: `npm run build`.

В этой версии действия с автомобилями, оплата и SMS демонстрационные. Фотографии машин загружаются по внешним ссылкам, для их отображения нужен интернет.

При проверке в среде подготовки `npm install` завершился по тайм-ауту; сборка здесь не была подтверждена.
